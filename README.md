## Yang sedang saya kerjakan

- **Sistem Informasi Akuntansi Otomotif** (repository privat): aplikasi tugas kuliah yang mensimulasikan pembukuan perusahaan suku cadang, mencakup empat siklus akuntansi (pendapatan, pengeluaran, produksi, SDM dan penggajian) dengan jurnal otomatis ke buku besar, pengendalian akses per peran, dan alat pemantau progress tim. Dibangun dengan Next.js, TypeScript, dan Firebase, lengkap dengan rancangan basis data relasional yang dipecah per siklus.
- **sentinel** (repository privat): platform keamanan web terdistribusi dengan pemindaian DAST dan penambalan otomatis berbasis AST, monorepo poliglot (Next.js, Hono, Python, Go). Sengaja ditutup sampai arsitekturnya matang.
