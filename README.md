## Tentang Saya

Mahasiswa Sistem Informasi di UIN Syarif Hidayatullah Jakarta yang aktif membangun sistem full-stack dari nol sampai tahap produksi. Fokus saya bukan cuma menulis kode, tapi merancang arsitektur yang bisa dipakai nyata: mulai dari platform e-commerce, sistem manajemen inventori, automasi berbasis AI, sampai arsitektur keamanan siber tingkat enterprise.

Beberapa poin penting soal cara saya bekerja:

- Terbiasa membangun proyek end-to-end, dari desain database sampai deployment
- Sering bereksperimen dengan stack baru untuk memahami trade-off arsitektur, bukan sekadar ikut tren
- Menulis dokumentasi dan struktur repo serapi mungkin supaya proyek lama tetap bisa dibaca ulang
- Aktif mengikuti perkembangan teknologi terbaru di ekosistem JavaScript, TypeScript, dan security tooling
- Saat ini punya lebih dari 13 repository publik dan privat yang mencakup retail, esports, keuangan, perpustakaan digital, automasi voice, hingga platform DevSecOps

<br>

## Roadmap Karier

Target jangka panjang saya adalah posisi kepemimpinan di bidang cybersecurity di lingkungan BUMN, khususnya PT Biro Klasifikasi Indonesia. Berikut roadmap sertifikasi yang sedang saya susun:

| Tahap | Sertifikasi | Fokus | Status |
|---|---|---|---|
| 1 | eJPT | Dasar penetration testing | Direncanakan |
| 2 | OSCP | Offensive security praktikal | Direncanakan |
| 3 | CISM | Manajemen keamanan informasi | Direncanakan |
| 4 | CISSP | Kepemimpinan keamanan tingkat enterprise | Direncanakan |

Paralel dengan roadmap ini, proyek seperti `sentinel` (platform DAST dan auto-patching) saya bangun sebagai latihan langsung menerapkan konsep keamanan aplikasi di dunia nyata.

### premium - Digital Goods Storefront

<details>
<summary>Klik untuk detail lengkap</summary>
<br>

**Ringkasan**

### geprek-supply - Supplier Mapping Platform

<details>
<summary>Klik untuk detail lengkap</summary>
<br>

**Ringkasan**
Platform pemetaan dan smart routing yang menghubungkan warung ayam geprek dengan supplier bahan baku terdekat. Proyek ini juga menjadi deliverable akademik untuk mata kuliah Konsep Sistem Informasi.

**Fitur Utama**
- Filtering radius memakai formula Haversine
- Perhitungan estimasi waktu tempuh (ETA) berbasis rute nyata
- Rendering peta memakai MapLibre, bukan Google Maps, untuk efisiensi biaya
- Formula estimasi ongkos kirim mengikuti pola tarif ojek online
- Desain keamanan sederhana: admin ditentukan lewat environment variable, tanpa pendaftaran email dinamis

**Stack**
`React` `TypeScript` `MapLibre` `Node.js` `Express` `Prisma` `SQLite`

</details>

## Cara Saya Membangun Proyek

Pola kerja yang biasa saya pakai dari proyek ke proyek:

1. **Riset kebutuhan** — memahami masalah nyata sebelum menulis kode pertama, biasanya dari kasus di sekitar seperti warung, kampus, atau komunitas
2. **Rancang skema data** — menentukan struktur database dan relasi antar entitas sejak awal, bukan belakangan
3. **Bangun backend dulu** — API dan logika inti dibuat sebelum frontend disentuh, supaya kontrak data jelas
4. **Iterasi UI cepat** — frontend dibangun bertahap dengan komponen yang bisa dipakai ulang
5. **Dokumentasi dan pembersihan repo** — sebelum dianggap selesai, struktur folder dan README proyek dirapikan
