## What I am working on

- **Automotive Accounting Information System** (private repository): a coursework application that simulates the books of an auto parts company across four accounting cycles (revenue, expenditure, production, HR and payroll), with automatic journal posting to the general ledger, role-based access control, and a team progress tracker. Built with Next.js, TypeScript, and Firebase, together with a relational database design split per cycle.
- **sentinel** (private repository): a distributed web-security platform with DAST scanning and AST-aware auto-patching, as a polyglot monorepo (Next.js, Hono, Python, Go). Kept closed until the architecture matures.

## How I work

1. Understand a real problem first, usually from nearby cases: a warung, a campus, a community.
2. Design the data schema and its relations from the start, not afterwards.
3. Build the core logic and API before the interface, so the data contract is clear.
4. Tidy the repository structure and documentation before calling a project done.
